================================================================================
QUICK START COMMANDS
================================================================================

1. Setup (automated):
   chmod +x setup.sh
   ./setup.sh

2. Setup (manual):
   python3.10 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env

3. Start server:
   python -m uvicorn backend.app.main:app --reload

4. Access:
   - Web UI: http://localhost:8000/ui
   - API: http://localhost:8000/api/v1
   - Docs: http://localhost:8000/docs

================================================================================
API ENDPOINTS SUMMARY
================================================================================

POST   /api/v1/documents/upload          Upload document
POST   /api/v1/documents/process/{id}    Start processing
GET    /api/v1/documents/status/{id}     Check status
POST   /api/v1/documents/correct/{id}    Apply manual corrections
POST   /api/v1/documents/validate/{id}   Validate extraction
POST   /api/v1/documents/export/{id}     Export results (JSON/CSV)
GET    /api/v1/documents/health          Health check

================================================================================
PROCESSING PIPELINE
================================================================================

Upload Document
    ↓
Preprocessing (Deskew, Denoise, Binarize)
    ↓
OCR (Tesseract/PaddleOCR)
    ↓ Extracts: Text blocks, bounding boxes, confidence
Layout Analysis
    ↓ Extracts: Regions, tables, key-value pairs
LLM Extraction (Local llama.cpp)
    ↓ Extracts: Structured JSON data
Validation & Confidence Scoring
    ↓
Export (JSON/CSV)
